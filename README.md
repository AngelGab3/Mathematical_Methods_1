# Mathematical Methods I

This repository contains a collection of mathematical documents and notes written in LaTeX, focusing primarily on the fundamentals of differential geometry and advanced calculus.

## Repository Content

The repository is organized into thematic folders. Each directory includes the source code (`.tex`) and its respective compiled version for reading (`.pdf`):

*   **1_Forms**: Notes and mathematical formulations on differential 1-forms.
*   **Curves_in_Euclidean_Space**: Study, properties, and parameterization of curves in Euclidean space.
*   **Directional_Derivative**: Notes and examples on the directional derivative.
*   **Euclidean_Space**: Concepts and metric foundations of Euclidean space.
*   **Exterior_Derivative**: Documentation on the exterior derivative applied to differential forms.
*   **Tangent_Space**: Definitions and development of the tangent space concept.

## Technologies and Formats

*   **LaTeX**: All content is developed in `.tex` to ensure high-quality mathematical typography.
*   **PDF**: Each section has its final `.pdf` document ready for reference.

## How to Use This Repository

You can navigate through each of the folders to study specific topics. If you wish to edit or compile the documents on your own, you will need a LaTeX distribution (such as TeX Live or MiKTeX) or an online editor like Overleaf to process the `.tex` files.
