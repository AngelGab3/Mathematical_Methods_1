# Problem Sheets / Hojas de Problemas

This directory is reserved for problem sets, analytical exercises, and practical problem-solving worksheets associated with the topics covered in **Mathematical Methods I**.

---

### Organization

* **Problem Sets**: Analytical problems covering Euclidean geometry, moving frames, differential forms, tensor calculus, and invariant operators.
* **Format**: Documents will be provided in both LaTeX source (`.tex`) and compiled documents (`.pdf`).

---

### Organización (Español)

Este directorio está destinado a la publicación de hojas de ejercicios, problemas analíticos y talleres prácticos asociados a los contenidos de **Métodos Matemáticos I**.

* **Contenido**: Ejercicios estructurados en geometría euclídea, sistemas de referencia móviles, formas diferenciales, cálculo tensorial y operadores invariantes.
* **Formato**: Los enunciados y soluciones se proporcionan en formato fuente LaTeX (`.tex`) y compilado (`.pdf`).
